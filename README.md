# Arulmathi Silks Website

Production website for Arulmathi Silks, built with React, Vite, and Tailwind CSS.

## Requirements

- Node.js 18 or newer
- npm 9 or newer

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Vite writes the production bundle to `dist/`. Dependencies and build output are generated locally and are intentionally excluded from Git.

## Project structure

```text
public/          Static images and videos
src/components/ React page and shared UI components
src/data/       Product and collection data
src/utils/      Shared application utilities
src/App.jsx     Route composition and application shell
src/main.jsx    React entry point
```
